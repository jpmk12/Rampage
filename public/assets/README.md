# public/assets/

Drop real game art here to replace the code-drawn placeholders.

- Put **PNG** files (transparent background) in **`sprites/`**.
- Register each one in **`src/data/assets.js`** (uncomment its line).
- Full instructions, sizes, and where to get free art:
  **[../../docs/ASSETS.md](../../docs/ASSETS.md)**

Files here are copied to the site root at build time, so a sprite at
`public/assets/sprites/goblin.png` is served as `assets/sprites/goblin.png`.
